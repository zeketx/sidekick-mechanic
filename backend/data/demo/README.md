# Demo-mode bay photos

Public 2JZ engine-bay photos for the chat-to-highlight UX playground. **Not Zeke's truck.** Polygons and `demo_state` values in `demo_bay_photos.json` are scripted demo data, not measured gates.

Licenses and credit: [ATTRIBUTION.md](ATTRIBUTION.md). The Hilux photo is **CC BY-SA 3.0** — the photo and any adaptation (including a highlighted screenshot) must be shared under the same license with credit.

Image files live in `photos/`. They are resized stand-ins (long side at most 1600 px). Do not treat them as the owner's bay map.
