# Wireframes

Low-fi iPhone frames for the owner-review design. Grayscale boxes and placeholder copy only.

Regenerate from the repo root:

```bash
python3 docs/design/wireframes/generate_wireframes.py
```

The script is stdlib for SVG. PNG also writes if `cairosvg` is installed (`pip install cairosvg`).

Placeholder bay drawings are not Zeke's truck. Copy uses `FAKE-DOC-2JZ`, `p. 999`, and `FAKE-SPEC`. No torque, pinout, wire color, part number, or firing order. The 2JZ-GE is naturally aspirated; there is no turbo in these frames.
